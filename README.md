# محاكي الطبيب النفسي — نسخة نشر مباشرة

هذه نسخة اللعبة المبنية، جاهزة للنشر من main و/(root). لا تحتاج تشغيل npm أو GitHub Actions مخصص لبناء React.

1. فك ZIP ثم ارفع محتوياته إلى جذر مستودع GitHub على فرع main. يجب أن يظهر index.html ومجلد assets مباشرة في صفحة الملفات.
2. ارفع ملف .nojekyll أيضًا. إذا لم يظهر ضمن الملفات في جهازك، أنشئ ملفًا بهذا الاسم في جذر المستودع من Add file → Create new file، ثم احفظه.
3. افتح Settings → Pages.
4. اختر Source: Deploy from a branch.
5. اختر Branch: main والمجلد: /(root)، ثم Save.
6. انتظر اكتمال النشر، ثم افتح رابط الموقع وأدخل مفتاح Gemini داخل إعدادات اللعبة.

المسارات نسبية، لذا تعمل النسخة لأي اسم مستودع. لا ترفع ZIP نفسه ولا تضع محتوياته داخل مجلد إضافي.

إذا كنت رفعت مشروع المصدر السابق، استبدل index.html بالنسخة المبنية وارفع مجلد assets الموجود في هذا ZIP. أزل ملف .github/workflows/pages.yml القديم من المستودع حتى لا يستمر مسار النشر المخصص بالتشغيل. يمكن إبقاء src وبقية المصدر إن رغبت؛ النشر المباشر يستخدم index.html وassets فقط.

البناء وفحص TypeScript نجحا. النسخة مبنية من المشروع الذي اجتاز 31 اختبارًا و12 اختبار متصفح بأربعة مقاسات. تم فحص مسارات ملفات البناء والصور تحت مسار مستودع تجريبي. لا توجد مفاتيح API في الحزمة. الاتصال الحي يحتاج مفتاحك واختبار الاتصال من إعدادات اللعبة.

المصدر القابل للتعديل موجود في ZIP المشروع الكامل الذي سُلّم سابقًا؛ هذا الملف مخصص للرفع المباشر فقط. لم يتم تنفيذ أي نشر أو push أثناء تجهيز النسخة.
